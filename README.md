## 1. Project Description

**Football Match Prediction System** is a Flutter-based mobile application developed as part of the UI Design using Flutter Laboratory (CS506PC).  

The application allows users to view football matches, make score predictions, and explore various Flutter UI concepts such as widgets, layouts, responsive design, navigation, state management, forms, animations, REST API integration, and testing.

This project is structured experiment-wise as per the laboratory guidelines and demonstrates progressive development through meaningful Git commits.
